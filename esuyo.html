E-Suyo

Your guide to commuting in Albay — mobile app & interactive web map

E-Suyo is a commuting guide for the Albay region — available as a mobile app and an interactive web map. Explore jeepney routes, calculate fares with senior/PWD discounts, track rides, find landmarks, and simulate routes. Built for both passengers and operators.

Features
Route Management
Browse, create, and manage PUJ, MPUJ, PUB, PUB w/AC, and UV Express routes across Albay.
Jeepney Fare Calculator
Instantly compute fares with support for senior citizen and PWD discount rates.
Landmark Finder
Add, filter, and navigate to categorized landmarks around the city.
Route Simulation
Animate and simulate jeepney routes with stop-by-stop playback on the interactive map.
QR Code Generator
Generate QR codes for any route so passengers can scan and view route details instantly.
Schedules & Stops
View operating hours, stop sequences, and frequency info for every route.
Vehicle Type Filter
Filter routes by vehicle type — PUJ, MPUJ, PUB City, PUB w/AC, or UV Express.
Feedback System
Submit route feedback, report issues, or suggest improvements directly in the app.
